API Reference

The nepal_admin_api package provides a complete, type-safe API for querying Nepal's administrative divisions. All data is embedded at compile time — zero runtime dependencies, fully offline.

Import
import 'package:nepal_admin_api/nepal_admin_api.dart';

Key Features

  • Hierarchical access — Province → District → LocalBody
  • Typed search — Disambiguates duplicate names by district/province context
  • CBS/NSO codes — Official 5-digit PDDPP codes (v2.0.0+)
  • ISO 3166-2 — Province codes NP-P1 through NP-P7
  • JSON serialization — toJson() / fromJson() on all models
  • Computed stats — National and provincial totals, not hardcoded

Models

LocalBodyType enum

Represents the four types of local bodies in Nepal's federal structure.

enum LocalBodyType { metropolitan, // 6 nationwide subMetropolitan, // 11 nationwide municipality, // 276 nationwide ruralMunicipality, // 460 nationwide unknown // fallback for deserialization }

Properties:

  • shortName — Abbreviation (e.g., "M", "RM", "Metro", "Sub-Metro")
  • fullName — Human-readable name (e.g., "Municipality", "Rural Municipality")

Static method: LocalBodyType.fromShort(String?) — resolves abbreviation to enum.

Province

One of Nepal's 7 provinces.

class Province { final String id; // e.g., "koshi", "bagmati" final String name; // e.g., "Koshi", "Bagmati" final int cbsCode; // 1-7 (NEW in v2) final String isoCode; // "NP-P1".."NP-P7" (NEW in v2) final ProvinceStats stats; final List districts; }

Constructor (v2): Requires cbsCode and isoCode.

District

One of Nepal's 77 districts, belonging to a province.

class District { final String name; final int? cbsCode; // 3-digit (e.g., 306 for Kathmandu) — NEW in v2 final List localBodies; // getter final int localBodyCount; // getter final String provinceName; // getter (set by Province) // v2 Constructor District({required name, cbsCode, required List units}) }

Note: units parameter is now List (was List<(String, LocalBodyType)> in v1).

LocalBody

A single local body (palika) — metropolitan, sub-metropolitan, municipality, or rural municipality.

class LocalBody { final String name; final LocalBodyType type; final String districtName; final String provinceName; final int? cbsCode; // 5-digit PDDPP (NEW in v2) final bool cbsCodeVerified; // doubly-attested by CBS + Postal-2025 (NEW in v2) final double? lat, lng; // WGS84 centroid, null when unmapped (NEW in v2.2) final String? geoSource; // e.g. 'open-admin-data' (NEW in v2.2) final int? wards; // ward count, null for 8 pending roster adjudication (NEW in v2.3) final bool wardsVerified; // doubly-attested sagautam5 + geo-pro-max (NEW in v2.3) // v2 Constructor (v2.2 adds lat/lng/geoSource; v2.3 adds wards/wardsVerified) LocalBody({ required name, required type, required districtName, required provinceName, cbsCode, cbsCodeVerified = false, lat, lng, geoSource, wards, wardsVerified = false }) // Properties String get typeName => type.fullName; bool get hasCoordinates => lat != null && lng != null; bool get isUrban => type == metropolitan || type == subMetropolitan || type == municipality; // Serialization Map toJson(); factory LocalBody.fromJson(Map json); }

CBS Code Format (PDDPP): 5 digits = 3-digit district code + 2-digit palika number.
Example: 31304 = district 313 (Chitwan), palika 04 (Bharatpur). Kathmandu district is 306, so 30601 is a Kathmandu palika.

NepalAdminApi

Static class providing all query methods.

getAllProvinces static

List getAllProvinces()

Returns all 7 provinces.

getProvinceById static

Province? getProvinceById(String id)

Case-insensitive lookup by province ID (e.g., "bagmati") or ISO 3166-2 code (e.g., "NP-P3"). Returns null if not found. For explicit ISO lookup see getProvinceByIso.

getAllDistricts static

List getAllDistricts()

Returns all 77 districts, flattened across provinces.

getDistrictsByProvince static

List getDistrictsByProvince(String provinceId)

Returns districts belonging to a province (by ID). Empty list if province unknown.

getDistrictByName static

District? getDistrictByName(String name)

Case-insensitive lookup by district name (e.g., "chitwan"). Returns null if not found.

getAllLocalBodies static

List getAllLocalBodies()

Returns all 753 local bodies, flattened across all districts.

getLocalBodiesByDistrict static

List getLocalBodiesByDistrict(String districtName)

Returns local bodies belonging to a district (case-insensitive). Empty list if district unknown.

v2.1 code-first lookups static

Province? getProvinceByIso(String isoCode) Province? getProvinceByCbs(int cbsCode) District? getDistrictByCbs(int cbsCode) LocalBody? getLocalBodyByCbs(int cbsCode) List<LocalBody> getLocalBodiesByProvince(String provinceId) List<LocalBody> getLocalBodiesByType(LocalBodyType type) List<LocalBody> getVerifiedLocalBodies()

getProvinceByIso('NP-P3') → Bagmati. getDistrictByCbs(306) → Kathmandu. getLocalBodyByCbs(31304) → Bharatpur (null when unverified). getDistrictsByProvince / getLocalBodiesByProvince accept an id or ISO code. getVerifiedLocalBodies() returns the 547 CBS-verified palikas.

v2.1 helpers + extensions

String LocalBody.fullPath // 'Bharatpur, Chitwan, Bagmati' bool LocalBody.isRural List<LocalBody> District.localBodiesByType(LocalBodyType type) List<LocalBody> District.verifiedLocalBodies List<LocalBody> Province.localBodies extension LocalBodyListX { sortedByName, sortedByFullPath, whereUrban, whereRural, whereVerified, ofType(LocalBodyType type) }

Use fullPath for dropdown labels and breadcrumbs — it disambiguates duplicate names (e.g. four Sunkoshis). search() also matches ISO codes and full paths since v2.1.

getNationalStats static

NationalStats getNationalStats()

Computes national totals live from the dataset.

search static

SearchResult search(String query)

Case-insensitive search across provinces, districts, and local bodies. Local body names are not unique nationwide — always use LocalBody.districtName and LocalBody.provinceName to disambiguate.

Example:
Dart
final result = NepalAdminApi.search('Bharatpur');
// result.localBodies contains matches with district/province context
for (final lb in result.localBodies) {
  print('${lb.name} - ${lb.districtName}, ${lb.provinceName}');
}

Usage Examples

Basic Lookups

Dart
// All provinces
final provinces = NepalAdminApi.getAllProvinces();

// Province by ID (case-insensitive)
final koshi = NepalAdminApi.getProvinceById('koshi');
final byIso = NepalAdminApi.getProvinceById('NP-P1');

// District by name
final chitwan = NepalAdminApi.getDistrictByName('chitwan');
print(chitwan?.localBodyCount); // 7

// Local bodies in a district
final bodies = NepalAdminApi.getLocalBodiesByDistrict('Kathmandu');
for (final lb in bodies) {
  print('${lb.name} (${lb.typeName})');
}

Working with CBS Codes (v2)

Dart
final bharatpur = NepalAdminApi.search('Bharatpur').localBodies.first;

print('Name: ${bharatpur.name}');
print('Type: ${bharatpur.typeName}');
print('District: ${bharatpur.districtName}');
print('Province: ${bharatpur.provinceName}');

// CBS code (5-digit PDDPP)
if (bharatpur.cbsCode != null) {
  print('CBS Code: ${bharatpur.cbsCode}');
  print('Verified: ${bharatpur.cbsCodeVerified}');
}

// Province ISO code
final province = NepalAdminApi.getProvinceById('NP-P3');
print('ISO: ${province?.isoCode}'); // NP-P3
print('CBS: ${province?.cbsCode}'); // 3

JSON Serialization

Dart
final lb = NepalAdminApi.search('Bharatpur').localBodies.first;

// To JSON
final json = lb.toJson();
// {
//   "name": "Bharatpur",
//   "type": "M",
//   "district": "Chitwan",
//   "province": "Bagmati",
//   "cbsCode": 31304,
//   "cbsCodeVerified": true
// }

// From JSON
final restored = LocalBody.fromJson(json);
assert(restored.name == lb.name);
assert(restored.type == lb.type);

National Statistics

Dart
final stats = NepalAdminApi.getNationalStats();

print('Provinces: ${stats.provinces}');        // 7
print('Districts: ${stats.districts}');        // 77
print('Metropolitan: ${stats.metro}');         // 6
print('Sub-Metro: ${stats.subMetro}');         // 11
print('Municipalities: ${stats.municipalities}'); // 276
print('Rural Municipalities: ${stats.ruralMunicipalities}'); // 460
print('Total: ${stats.total}');                // 753
print('Wards: ${stats.wards}');                // 6743

Migration Guide: v1 → v2

Version 2.0.0 introduces breaking changes to include official CBS/NSO codes.

Breaking Changes

Component v1 v2
LocalBody LocalBody({name, type, districtName, provinceName}) LocalBody({name, type, districtName, provinceName, cbsCode?, cbsCodeVerified?})
District District({name, units: List<(String, LocalBodyType)>, provinceName?}) District({name, cbsCode?, units: List, provinceName?})
Province Province({id, name, stats, districts}) Province({id, name, cbsCode, isoCode, stats, districts})

Migration Steps

  1. Update pubspec.yaml: nepal_admin_api: ^2.0.0
  2. Run dart pub get
  3. Fix constructor calls:
    • LocalBody(...) — add optional cbsCode, cbsCodeVerified params
    • District(...) — pass List for units, optional cbsCode
    • Province(...) — add required cbsCode and isoCode
  4. Use new fields: lb.cbsCode, lb.cbsCodeVerified, d.cbsCode, p.isoCode

New Capabilities

  • Look up by ISO code: getProvinceById('NP-P3')
  • Check CBS verification: lb.cbsCodeVerified (547/753 verified)
  • District codes: district.cbsCode (3-digit)
